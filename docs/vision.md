# Бачення проєкту «Система управління студентами»

## Мета
Створити єдину систему обліку студентів, академічних груп, дисциплін і оцінок. Викладачі ведуть відомості, а студенти переглядають лише власну успішність.

## Користувачі
| Роль | Потреби |
| --- | --- |
| Викладач | Додавати, шукати студентів, переглядати групи, виставляти й виправляти оцінки. |
| Студент | Увійти до системи та переглянути власні оцінки. |
| Адміністратор | Керувати обліковими записами, правами й розгортанням. |


## Основні функції
- Облік студентів: додавання, перегляд, редагування та видалення.
- Облік академічних груп і дисциплін.
- Виставлення й редагування цілих оцінок 0–100.
- Пошук за прізвищем і фільтрація за групою.
- Автентифікація та доступ студента лише до власних оцінок.
- REST API з JSON і клієнт Vue.js.
- Експорт CSV і Docker Compose як додаткові можливості.

## Поза межами проєкту

- Вступ і державні реєстри; паспортні, банківські та медичні дані.
